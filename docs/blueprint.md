# **App Name**: Wildcat Confessions

## Core Features:

- Anonymous Confession Posting: Allow users to submit confessions without revealing their identity.
- Real-time Confession Feed: Display a live stream of new and existing confessions for immediate viewing.
- Reaction System: Enable users to react to confessions using minimal, intuitive icons (e.g., heart, fire, laugh).
- Threaded Comment System: Provide a clean, organized system for users to post and reply to comments on confessions.
- Confession Categorization: Allow confessions to be assigned and filtered by specific categories (e.g., Crushes, Rants, Tea, Memes).
- Search and Filtering: Implement robust search and filtering capabilities to help users find specific confessions or topics.
- Trending Section: Showcase confessions that are currently popular or receiving high engagement.
- Report/Flag System: Allow users to report inappropriate or problematic content for moderation.
- Admin Moderation Dashboard: A dedicated interface for administrators to manage and moderate user-generated content.
- Content Filtering Logic: Backend system to automatically detect and filter out inappropriate content based on predefined rules.

## Style Guidelines:

- Primary color: Maroon (#6B0F1A), used for key elements and branding.
- Accent color: Muted gold (#C9A227), for interactive elements like buttons and highlights.
- Background color: White or a very light off-white, maximizing whitespace for a clean look.
- Headline and body font: A clean, highly readable sans-serif typeface like Inter or Poppins for all text.
- Use minimalist, simple outline-style icons for reactions and navigation, avoiding clutter.
- Clean, modern, and minimalist design with generous use of whitespace.
- Centered main content feed within a narrow column for focused reading.
- Top fixed navigation bar containing logo, category links, and search functionality.
- Floating 'Post Confession' button positioned prominently with the muted gold accent.
- Confessions displayed using a card-based layout with rounded corners and subtle shadows.
- Fully responsive layout, designed mobile-first for seamless experience across devices.
